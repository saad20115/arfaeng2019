# شركة عرفة للأنظمة المتخصصة - ARFA SPECIALIZED SYSTEMS
## Odoo 19 Custom Addons & Enterprise Website Platform

موانع وتطبيقات الموقع الإلكتروني والأنظمة المتخصصة لشركة عرفة الهندسية للمقاولات العامة والأنظمة الكهروميكانيكية والمباني الذكية بالمملكة العربية السعودية.

---

### 🌟 مميزات النظام والوظائف الأساسية (Key Features):
1. **الموقع الإلكتروني المتكامل والاحترافي (Bilingual Website)**:
   - دعم كامل للغتين العربية والإنجليزية مع إمكانية التبديل الفوري.
   - تصميم زجاجي عصري (Glassmorphic Modern UI) مطابق لأحدث معايير تجربة المستخدم.

2. **التوافق التام مع محركات البحث (SEO & Social Sharing Ready)**:
   - بطاقات التفاعل الاجتماعي (`Open Graph` & `Twitter Cards`) للمشاركة الفورية على الواتساب ولينكد إن وتويتر.
   - كود البيانات المهيكلة لجوجل (`Schema.org JSON-LD Rich Snippets`).
   - ملف `robots.txt` وخريطة موقع ديناميكية `sitemap.xml`.

3. **ربط النماذج بخادم البريد الإلكتروني (Mail Server Integration)**:
   - إصدار رقم مرجعي مميز لكل طلب تلقائياً (مثل `REQ-WASM-2026-XXXXX`).
   - إرسال إشعارات فورية للإدارة عند ورود أي طلب جديد بضغطة زر لفتح الطلب في أودو.
   - إرسال بريد تأكيد تلقائي للعميل يتضمن الرقم المرجعي لمتابعة طلبه.

4. **لوحة تحكم كاملة في المحتوى (Odoo Backend Control Panel)**:
   - إدارة المشاريع المعروضة، الخدمات، الشركاء، الأخبار، معرض الصور، وتعديل وسائط الموقع بسهولة.

---

### 🛠️ كيفية التشغيل والتثبيت (Setup & Execution):
```bash
# تشغيل الخادم
./run_odoo.sh -d arfa2026

# تحديث مديول الموقع
./run_odoo.sh -d arfa2026 -u wasm_website --stop-after-init
```
